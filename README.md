# 🧩 Teka Teki Silang

Aplikasi Teka Teki Silang (TTS) untuk Android.

## 🎮 Sistem Level

Tersedia **500 level** yang dapat dimainkan secara bertahap.

| Level | Tingkat |
|---|---|
| 1–50 | 🟢 Pemula |
| 51–100 | 🟡 Mudah |
| 101–150 | 🟠 Menengah |
| 151–200 | 🔵 Menengah Atas |
| 201–250 | 🟣 Sulit |
| 251–300 | 🔴 Sangat Sulit |
| 301–350 | ⚫ Expert |
| 351–400 | 🔥 Master |
| 401–450 | 💎 Grand Master |
| 451–500 | 👑 Legenda |

## ✨ Fitur

- 🧩 500 level Teka Teki Silang
- 📅 TTS harian
- 💡 Petunjuk
- 🪙 Koin bantuan
- 🔥 Streak bermain
- 🏆 Leaderboard
- 🌙 Dark Mode
- 📶 Bisa dimainkan offline
- 🔊 Efek suara jawaban benar dan salah
- 🎁 Rewarded Ads untuk mendapatkan koin
- 🚫 Tidak ada iklan yang mengganggu saat bermain

## 🪙 Sistem Koin

Pemain dapat memperoleh koin dengan menonton **iklan berhadiah (Rewarded Ads)** secara sukarela.

Koin dapat digunakan untuk mendapatkan bantuan saat mengerjakan TTS.

## 🚀 Status Project

**Dalam pengembangan 🚧**

Project ini akan dikembangkan secara bertahap mulai dari sistem permainan dasar hingga seluruh **500 level** selesai.
